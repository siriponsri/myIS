# myIS Research Notes

นี่คือ Obsidian vault แบบ Git-tracked สำหรับอ่านสถานะ วิธีการ และ handoff
สำหรับ Owner ระดับ beginner

- `generated/` สร้างใหม่ได้จาก Research manifests, `HANDOFF.md` และ session receipts
- `owner_notes/` เป็นพื้นที่จดของ Owner และ generator จะไม่เขียนทับ
- `_templates/` แบบฟอร์ม note ที่ใช้ซ้ำ
- `_sources/` บันทึกแนวทาง notebook, provenance และ Obsidian

Git และ validated manifests ใน `01_Research` เป็น scientific authority เสมอ
Notes เป็น projection สำหรับการอ่าน ไม่ใช่ที่เก็บ qrels, query IDs หรือผลราย query
