# Track C - Candidate Exposure

Primary claim: CrossRoute increases family-level `OUT Recall@100` relative to
one preregistered protocol-matched reproduced baseline under the same final
candidate budget.

Order: F1 reproduction -> C0 OUT-positive/power/oracle audit -> C1 grounded
manual routes/views -> optional C2 bounded policy optimization -> CF immutable
pool freeze.

Selection accepts only a strictly greater primary score and rejects ties. Route
analysis reports Recall@100/200/1000, coverage, zero-hit rate, unique relevant
families, overlap, ALL/IN diagnostics, cost, and provenance. MDE is prospective
design sensitivity only.

Confirmation is external and aggregate-only. A positive point delta is observed
improvement; CI lower > 0 supports superiority; a positive delta with a CI
crossing zero is a higher measured score with uncertain superiority.
