# ArmIndex Roadmap

1. `A0_MIGRATION_FOUNDATION`: migrate authority and projections; validate synthetic fixtures.
2. `A1_BASELINES_AND_MULTI_ARM_SCREENING`: reproduce controls and screen five arms.
3. `A2_PER_ARM_AUTOINDEX`: freeze one program per promoted arm.
4. `A3_TRANSFER_COMPLEMENTARITY_AND_HARNESSOPT`: freeze the arm set and harness.
5. `A4_PRODUCTION_TRANSFER_AND_SELECTION`: freeze profiles, transfer result, and champions.
6. `A5_FINAL_CONFIRMATION`: run one frozen confirmation after `D2_OPEN_FINAL`.
7. `A6_FULL_DAPFAM_MATERIALIZATION_AND_SCALABILITY`: generate the A5-frozen ARM-03 Top-200 family pool for all 1,247 DAPFAM queries, compute Owner-local ALL/IN/OUT retrieval metrics, safe-return the pool, and report operational scalability; no tuning, selection, or final feedback.
8. `A7_SEVEN_LAYER_RETRIEVAL_DIAGNOSIS`: run the seven-layer retrieval diagnosis and comparison framework over immutable A6 evidence, with optional fixed-reference L3R only when freshly admitted.
9. `A8_JOURNAL_SYNTHESIS_AND_PUBLICATION`: build the journal manuscript and release package after `D3_SUBMIT_RELEASE` from validated A0-A7 aggregate-safe evidence.

Only Phase and Task are canonical levels. The roadmap creates no additional
Owner gates or micro-phases.
