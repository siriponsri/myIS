# ArmIndex Slide Figures

This directory contains presentation-ready, aggregate-safe explanatory figures.
They do not contain raw DAPFAM records, query IDs, qrels, rankings, per-query
outcomes, credentials, or unvalidated A2 metrics.

| File | Role | Evidence status |
|---|---|---|
| `dapfam-protocol.svg` | Dataset structure and split roles | Protocol facts from `control/assets/dapfam-p1-source.v1.json` |
| `patent-retrieval-pipeline.svg` | Retrieval architecture and representation choices | Study-design diagram |
| `armindex-research-program.svg` | Phase narrative from A0 through A3 | A2 measured closeout; A3 waits for a hash-bound Train-250 package |
| `a2-to-a3-gated-flow.svg` | A2 candidate execution and the A3 admission gate | A2 closeout and three-primary A3 admission diagram; not an outcome figure |
