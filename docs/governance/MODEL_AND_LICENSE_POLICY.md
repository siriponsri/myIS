# Model and License Policy

Every ArmIndex adapter must freeze the upstream repository ID, resolved
revision, tokenizer hash, remote-code hash when applicable, input format,
pooling, normalization, dimension, max length, truncation, precision,
quantization, similarity, dependency versions, and license snapshot.

PatEmbed-large is planned only for research/non-commercial use under its
declared CC BY-NC-SA 4.0 license. It cannot become the commercial-capable
champion or enter a commercial production profile automatically. BGE-M3,
Snowflake, and Qwen are planned as commercial-capable subject to verification
of the exact frozen revision and deployment conditions. Model licenses do not
grant a repository software license.

No fine-tuning, LoRA/QLoRA, adapter training, distillation, continued
pretraining, learned prompt, learned prefix, or weight modification is allowed.
