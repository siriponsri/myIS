# Template-Guided Figure Set

All four figures are generated by `source/generate_rebuilt.py` from the canonical
publication CSV ZIP. The generator parses the semantic palette directly from
`../template/theme.md` and asserts every displayed A3, A5, and A7 value before
exporting PDF, SVG, and 360-dpi PNG files.

## Overview evidence map

The four illustrated milestones follow the supplied overview template. The
dashed gate makes the development/protected-evaluation boundary explicit;
color distinguishes development, protected confirmation, and post-confirmatory
diagnosis without using background containers.

Final size: 7.16 x 1.43 inches.

## Figure 1: A3 transfer

Three target-specific panels preserve the supplied template's source shapes,
matched-pair outline, nominal-best amber mark, direct six-decimal labels, and
range annotations. Local axes are disclosed explicitly and the exact ranges
are printed to prevent the compact within-target views from overstating effect
size. The separated target bands make the dominant absolute retriever pattern
visible.

Final size: 7.16 x 2.33 inches.

## Figure 2: A5 confirmation

The supplied horizontal A/B/C structure is retained: absolute dumbbells,
paired effects with 95% confidence intervals, and an independent 100% W/T/L
strip. The Recall difference is the strongest annotation. Flat semantic color
replaces template gradients for vector and grayscale reliability.

Final size: 7.16 x 2.28 inches.

## Figure 3: A7 diagnosis

Panel A is an incidence-level 100% exposure partition with absence as the focal
takeaway. Panel B uses a point-to-point observed-to-bound interval and labels
the analytical headroom. Unit separation and the non-reranker boundary are
stated inside the figure.

Final size: 7.16 x 2.18 inches.
