# Research note guidance / แนวทางการบันทึกงานวิจัย

แหล่งอ้างอิงสำหรับโครงสร้าง note: Obsidian Properties, Templates, Internal
Links, Bases และ Obsidian URI; PLOS, “Ten Simple Rules for a Computational
Biologist's Laboratory Notebook” (doi:10.1371/journal.pcbi.1004385); FAIR
principles; W3C PROV-O; และ MLflow Tracking documentation

หลักที่นำมาใช้คือ metadata ที่ค้นได้, provenance ที่มี hash, ความสัมพันธ์
ระหว่าง note และการแยก entity/activity/agent ออกจากกัน เนื้อหาจริงของ DAPFAM
และ confirmation boundary ไม่ถูกคัดลอกมาไว้ใน note
