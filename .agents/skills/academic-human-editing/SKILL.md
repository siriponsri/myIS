# Academic Human Editing

This is **not an AI detector** and not an evasion tool.
It is a scientific prose quality pass.

Always load:
- `references/guardrails.md`

Load if needed:
- AI-pattern audit -> `references/observable-patterns.md`
- difficult prose -> `references/readability-pass.md`

## Workflow
1. Lock all numbers, results, citations, conditions, and technical meanings.
2. Diagnose observable prose problems.
3. Apply the **minimum effective edit**.
4. Prefer concrete propositions over style tricks.
5. Re-check that no claim became stronger.
6. Do not add personality, humor, or casual tone to the manuscript.

The target voice is neutral, precise, readable, and specific.
