# Scientific Figure Design — Question First

Always load:
- `references/figure-contract.md`
- `references/style-system.md`

Then:
- process/method figure -> `references/workflow-diagrams.md`
- data/result figure -> `references/data-plots.md`
- final review -> `references/qa.md`

## Rule
Do not start from a chart template. Start from the scientific question.

A figure must explain or prove something faster than prose/table can.

Prefer deterministic source files and vector export.
