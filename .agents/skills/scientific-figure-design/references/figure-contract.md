# Figure contract

Before drawing, write:

1. **Reader question** — what should the reader understand?
2. **One-sentence conclusion** — what is the visual answer?
3. **Evidence** — which data/process supports it?
4. **Archetype** — flow, comparison, trend, distribution, diagnostic, ablation, taxonomy.
5. **Final width** — IEEE one-column or two-column.
6. **Reading order** — where should the eye go first, second, third?
7. **Caption contract** — what context must be readable without the body text?

If a figure has two unrelated conclusions, split or redesign it.
