# Visual style system

Modern scientific design = **hierarchy + alignment + whitespace + restraint**.

Borrow from the user's workflow inspirations:
- clear stage grouping;
- directional arrows;
- visible hierarchy;
- consistent box geometry;
- strong alignment;
- whitespace around clusters.

Translate that into publication style:
- mostly neutral tones with one restrained accent family;
- grayscale-safe meaning;
- line/marker redundancy when color encodes categories;
- no gradients or 3D;
- no dashboard cards;
- no ornamental icons unless they carry information;
- no tiny text packed into boxes;
- keep labels short;
- use captions for detail rather than shrinking text.

A colorful infographic may be attractive at poster size but fail at IEEE column width.
Design at final manuscript size from the start.
