# Paper Layout and Space

## Rule zero
Never fix page overflow by cheating the template.

Do not modify required:
- margins;
- body font;
- line spacing;
- column geometry;
- page size.

## Venue mode
### iSAI-NLP / IEEE
Template is immutable.
Modern appearance must come from editorial hierarchy and visual discipline.

### WPI / Elsevier
Follow the journal submission/layout requirements.
Do not make a conference-style two-column aesthetic the default unless the journal template requires it.

## Page-purpose audit
For each page identify:
- dominant purpose;
- most important visual/text block;
- overloaded zone;
- dead whitespace;
- repeated material;
- awkward heading/caption break;
- element that should be deleted/merged.

## Six-page conference budgeting
Prioritize in this order:
1. research question and contribution;
2. method needed for understanding/reproducibility;
3. experimental validity;
4. central evidence;
5. limitations needed to calibrate claims;
6. related work/background;
7. secondary analyses.

If overflow occurs, cut from the bottom of this priority order first unless scientific validity would suffer.

## Density
Good density means high information per area, not small typography.

Prefer:
- shorter paragraphs;
- informative headings;
- compact captions;
- one strong figure;
- one compact comparison table;
- removing redundant prose.

Avoid:
- walls of text;
- half-empty pages caused by poor float placement;
- tiny figures floating inside large blank regions;
- tables that span width for only two meaningful columns;
- captions longer than the argument they support.

## Float logic
Place figure/table near first substantive discussion.
Do not make the reader turn a page to understand a result if avoidable.

## Visual hierarchy
The eye should find:
1. section;
2. figure/table/result;
3. interpretation.

Decorative hierarchy is not scientific hierarchy.

## Final audit
Render PDF and inspect actual pages.
Source code alone is insufficient for layout QA.
