# Adapting WPI material to iSAI-NLP

WPI journal content is a source of:
- patent-retrieval framing;
- literature synthesis;
- detailed method explanation;
- validated results;
- limitations;
- figure/table concepts.

For iSAI-NLP:
- re-author, do not merely shorten;
- lead with the NLP/IR research question;
- keep patent-specific context only when it changes the methodological problem;
- compress journal-level detail;
- retain the strongest defensible evidence;
- remove identity-revealing repository/organization details;
- use IEEE conference layout, not WPI layout.

Venue priority:
`iSAI-NLP rules -> IEEE template -> scientific clarity -> aesthetic preference -> WPI visual inspiration`.
