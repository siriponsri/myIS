# Scientific story arc

Use:
`Problem -> Gap -> RQ -> Method -> Experimental Design -> Result -> Interpretation -> Limitation -> Contribution`

Scientific storytelling differs from entertainment:
- state central points early;
- do not create mystery;
- do not hide a key result for a reveal;
- do not narrate experiments strictly in chronological order if another order is clearer.

Treat the outline like a storyboard:
- main figures/results = main plot;
- secondary diagnostics = supporting subplots;
- order them for comprehension, not historical sequence.

For a six-page paper:
- Introduction should quickly narrow from field/problem to exact gap and response.
- Results should be ordered by the research questions the reader must resolve.
- Discussion should explain meaning and limits, not restate the results.
