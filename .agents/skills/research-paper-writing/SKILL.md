# Research Paper Writing — Compact Router

Load only what the task needs.

Always load:
- `references/core-contract.md`

Then:
- story/outline/introduction/results flow -> `references/story-arc.md`
- section drafting -> `references/section-guides.md`
- equation or dense technical prose -> `references/equation-readability.md`
- page pressure / conference compression -> `references/six-page-economy.md`
- adapting WPI material -> `references/wpi-to-isainlp.md`

## Core behavior

1. Start from the claim and evidence, not from polished prose.
2. Write the one-sentence paper argument before rewriting sections.
3. If evidence is missing, narrow the claim or request analysis/experiment.
4. Make the central point visible early.
5. Do not add mathematical notation merely to sound scholarly.
6. Prefer clear technical English over ornate academic English.
7. Preserve every verified number, comparison, boundary, and citation meaning.
8. Never invent citations or results.
