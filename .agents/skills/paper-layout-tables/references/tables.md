# Scientific tables

A table answers one exact comparison question.

Keep:
- only necessary rows/columns;
- stable ordering;
- units in headers;
- consistent decimals;
- clearly defined abbreviations;
- fair comparison groups.

Avoid:
- vertical-rule clutter;
- decorative fills;
- five decimals when two or three suffice;
- bolding many cells;
- repeating every table value in prose;
- squeezing a large journal table into one IEEE column.

If exact values are not important and only the trend matters, use a figure.
