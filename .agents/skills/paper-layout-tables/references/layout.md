# Layout

Read the PDF, not only the TeX.

For every page identify:
- dominant purpose;
- densest region;
- dead whitespace;
- most important evidence;
- competing visual elements;
- awkward heading/float break;
- paragraph that can be removed/merged.

Modern IEEE appearance comes from:
- balanced columns;
- consistent heading rhythm;
- compact but breathable captions;
- aligned figures;
- readable tables;
- disciplined density.

It does not come from custom magazine styling.
