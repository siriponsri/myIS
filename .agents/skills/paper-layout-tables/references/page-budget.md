# Six-page page budget

Planning target, not a geometry hack:

- Page 1: title/abstract/introduction
- ~0.5 page: related work / positioning
- ~1.2–1.4 pages: method/experimental design
- ~1.5–1.8 pages: main results/diagnostics
- ~0.7–0.9 page: discussion/limitations/conclusion
- remaining space: references and required disclosure

Actual allocation follows evidence.

When over six pages:
1. remove duplicated argument;
2. shorten background;
3. consolidate result prose into table/figure;
4. remove low-value panel/column;
5. compress captions carefully;
6. remove nonessential equation/notation;
7. only then consider minor wording cuts.

Never change IEEE margins/font/line spacing.
